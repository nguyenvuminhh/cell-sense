# Support

## Common Issues

### Add-on not responding
- Refresh the Google Sheets page
- Re-open the add-on sidebar

### Formula errors
- Verify the generated formula syntax
- Check that referenced cells exist
- AI suggestions may need manual adjustment

### API key issues
- Ensure your API key is valid and has credits
- Check the key has correct permissions

## Getting Help

1. Check this page for common solutions
2. Review error messages in the sidebar
3. Open an issue on the project repository

## Feature Requests

Submit feature requests via the project repository issues.
