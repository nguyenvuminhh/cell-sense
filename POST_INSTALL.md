# Post-Install Tips

## Getting Started

1. Open any Google Sheets document
2. Navigate to **Extensions > AI Sheets Assistant**
3. Grant required permissions when prompted

## Quick Tips

- **Select data first:** Highlight relevant cells before asking questions
- **Be specific:** "Sum column A where B equals 'Sales'" works better than "add numbers"
- **Review before applying:** Always verify generated formulas

## Using Your Own API Key

1. Open the add-on settings
2. Choose your preferred LLM provider
3. Enter your API key
4. Select your preferred model

## Best Practices

- Start with simple queries to understand the AI's style
- Use chat history for follow-up questions
- Clear chat when switching to unrelated tasks
